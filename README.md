Discord Audio Bot

Bot de Discord feito em Python que toca um áudio quando determinadas pessoas mandam mensagens.

Funcionalidades
Envia e reproduz áudio em canais de voz.
Cadastro de vítimas por ID.
Salva os IDs em JSON.
Configuração por variáveis de ambiente.
Tecnologias
Python
discord.py
FFmpeg
Instalação
git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
cd SEU_REPOSITORIO
pip install -r requirements.txt


Configure o arquivo .env usando .env.example, coloque o áudio na pasta do projeto e execute:

python bot.py


Requisitos: Python e FFmpeg instalados, além de um bot configurado no Discord Developer Portal.
